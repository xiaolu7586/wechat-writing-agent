# 微信公众号写作专家

> OpenClaw Agent 配置 — 可用于任何兼容 OpenClaw 协议的 AI 产品

## 简介

这是一个专为微信公众号内容运营设计的 AI Agent，提供从选题规划到正式发布的**全流程 13 步工作流**。

## 核心功能

- 📊 **多平台热点扫描** — 聚合微博、知乎、百度、36Kr 等 8 个平台热榜
- 🔍 **竞品搜索分析** — 搜狗微信搜索 + 差异化角度提炼
- 📅 **内容日历生成** — 一键生成 5-10 个差异化选题推荐
- ✍️ **5 种写作风格** — 深度分析 / 实操教程 / 故事驱动 / 观点评论 / 快讯简报
- 🎨 **AI 配图生成** — Seedream 5.0 Lite 文生图 + 图生图
- 🖼️ **AI 封面生成** — 一键生成微信公众号封面（横图）
- 📤 **一键发布** — 支持 API / 浏览器 / wenyan-cli 多种发布渠道

## 🚀 零配置启动

**无需任何配置，直接开始使用。**

以下功能**无需任何配置**即可使用：

> 热点扫描 · 竞品分析 · 选题规划 · 内容日历 · 文章写作 · AI 配图 · AI 封面 · 浏览器发布

Agent 内置三个可选配置项（微信 AppID、AppSecret、IP 白名单），**均非必填**，留空或跳过不影响上述功能。详见下方「可选增强能力」。

## ✨ 可选增强能力

以下配置均为**锦上添花**，配置后可解锁更多自动化能力，不配置不影响正常使用。

### 增强 1：微信 API 自动发布（无需手动操作）

配置后，Agent 可直接通过微信 API 将文章推送到公众号草稿箱，全程自动化，无需打开浏览器。

**需要：** AppID + AppSecret + IP 白名单

**获取方式：** 登录 [微信公众平台](https://mp.weixin.qq.com) → 设置与开发 → 基本配置

配置后填入表单，或手动写入 `.secrets/wechat-config.json`：

```json
{
  "appid": "你的AppID",
  "secret": "你的AppSecret"
}
```

**IP 白名单：** 微信 API 要求调用方 IP 在白名单内，否则报 `ip not in whitelist`。

1. 让 Agent 执行 `curl ifconfig.me` 获取当前出口 IP
2. 登录微信公众平台 → 基本配置 → IP 白名单 → 添加 IP
3. 配置表单「IP 白名单」选「已在平台配置」

> AppSecret 重置后旧密钥立即失效，需重新填写。

### 增强 2：竞品搜索（搜狗微信）

**需要：** Node.js + cheerio

```bash
npm install -g cheerio
```

### 增强 3：AI 配图 & AI 封面生成

依赖平台内置的图片生成能力，平台支持则自动启用；不支持时自动降级为随机图片，不影响其他功能。

**需要：** Python 3 + openai + Pillow

```bash
pip install openai Pillow
```

### 增强 4：浏览器发布模式（无需 AppID）

**需要：** Google Chrome（[下载](https://chrome.com)）

Agent 控制 Chrome 自动完成发布，首次需扫码登录微信公众平台，之后保持登录状态。

### 各发布渠道能力对比

| 发布渠道 | 需要 AppID/Secret | 需要 IP 白名单 | 需要 Chrome |
|---------|-----------------|--------------|------------|
| **API 发布**（全自动） | ✅ | ✅ | ❌ |
| **浏览器发布**（零凭据） | ❌ | ❌ | ✅ |
| **wenyan-cli 发布** | ✅ | ✅ | ❌ |
| **浏览器贴图发布** | ❌ | ❌ | ✅ |

## 工作流

全流程共 13 步，3 个用户审批节点：

```
需求分析 → 需求诊断 → 热点扫描 → 竞品搜索 → 内容日历
    → ⛔ 用户确认选题
        → 风格选择 → 标题生成 → SEO关键词
            → 文章写作 + AI配图
                → ⛔ 用户确认大纲
                    → 封面生成 → 草稿推送
                        → ⛔ 用户确认发布
                            → 正式发布
```
